## 程式用途與執行方式

本程式用來計算朋友聚餐的分攤金額。程式會先將原始文字資料清理乾淨（去除前後空白、轉換大小寫、移除 `NT$` 與千分位逗號），接著將餐費與人數轉換為可運算的數值型別，依序計算 10% 服務費、扣除折價券後的應付總額與每人平均費用，最後透過布林比較判斷每人費用是否超過 300 元預算。

**執行方式**：將本儲存庫中的 `.ipynb` 筆記本檔案上傳至 Google Colab，依序執行三個程式碼區塊，即可重現三組測試的完整計算結果。

## 問題回答

### 1. 為什麼文字人數 `"4"` 要先轉成數字？
加上雙引號的 `"4"` 在 Python 中屬於字串（`str`），代表的是「文字」而不是可以拿來做算術運算的「數值」。如果直接拿餐費除以字串，Python 會因為資料型別不相容而報錯；就算做加法，`"4" + "1"` 也會變成文字串接的 `"41"`，而不是數學上的 `5`。因此必須先用 `int()` 把它轉換成整數 `4`，才能正確計算每人分攤的金額。

### 2. 如果先扣折價券再計算服務費，第一組總額為何會變成 1,210 元？
因為計算順序改變會讓服務費的計算基準不同。如果先扣掉 100 元折價券，餐費基準會先從 1,200 元降為 1,100 元；接著再以 1,100 元計算 10% 服務費，服務費就會變成 `1,100 × 0.10 = 110` 元（比原本以 1,200 元計算的 120 元少了 10 元），兩者相加後的總額因此變成 `1,100 + 110 = 1,210` 元。
